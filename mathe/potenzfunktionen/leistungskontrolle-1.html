EigenschaftenAufgabe 3 – Monotonie (3 P.)

Beschreibe, in welchen Bereichen der Graph steigt und in welchen er fällt.

a) y = x³ (1 P.)    b) y = x⁻² (1 P.)    c) y = x⁶ (1 P.)

Lösung anzeigen

a) y = x³ steigt im gesamten Definitionsbereich (n ungerade und positiv).
b) y = x⁻² steigt für x < 0 und fällt für x > 0. Beispiel: von x = −2 nach x = −1 wächst y von 0,25 auf 1; von x = 1 nach x = 2 sinkt y von 1 auf 0,25.
c) y = x⁶ fällt für x ≤ 0 und steigt für x ≥ 0 – wie die Normalparabel (n gerade und positiv).

EigenschaftenAufgabe 4 – Gemeinsame Punkte (3 P.)

a) Durch welchen Punkt gehen die Graphen aller Funktionen y = xⁿ? (1 P.)
b) Welche der Punkte O(0; 0), P(1; 1), Q(−1; 1) und R(−1; −1) liegen auf dem Graphen von y = x⁵? (1 P.)
c) Welche dieser Punkte liegen auf dem Graphen von y = x⁻⁴? (1 P.)

Lösung anzeigen

a) Durch P(1; 1), denn 1ⁿ = 1 für jeden Exponenten n.

b) y = x⁵: 0⁵ = 0, 1⁵ = 1, (−1)⁵ = −1
O(0; 0) liegt auf dem Graphen, P(1; 1) liegt auf dem Graphen, Q(−1; 1) liegt nicht auf dem Graphen, R(−1; −1) liegt auf dem Graphen.
c) y = x⁻⁴: x = 0 ist nicht erlaubt; 1⁻⁴ = 1, (−1)⁻⁴ = 1(−1)⁴ = 1
O(0; 0) liegt nicht auf dem Graphen, P(1; 1) liegt auf dem Graphen, Q(−1; 1) liegt auf dem Graphen, R(−1; −1) liegt nicht auf dem Graphen.

EigenschaftenAufgabe 5 – Wahr oder falsch? (2 P.)

Entscheide und begründe.

a) „Der Graph von y = x⁻¹ schneidet die x-Achse.“ (1 P.)
b) „Für 0 < x < 1 gilt x⁴ < x².“ (1 P.)

Lösung anzeigen

a) Falsch. y = 1x wird nie 0 – der Graph nähert sich der x-Achse nur an.
b) Wahr. Zahlen zwischen 0 und 1 werden beim Potenzieren kleiner, je größer der Exponent ist. Beispiel x = 0,5: 0,5⁴ = 0,0625 < 0,5² = 0,25.
